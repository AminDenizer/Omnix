# Omnix — Electronics Component & Warehouse Inventory Management

Omnix is a desktop application built with Python and PyQt6 for managing electronics components, SMD/THT parts, and multi-drawer storage cabinets.

## ✨ Features
- **Multi-Drawer Inventory Mapping**: Assign individual parts to multiple numbered drawer compartments with per-drawer stock accounting.
- **Modern Matte Dark Theme**: Engineered high-contrast dark UI with Persian RTL support and custom controls.
- **Smart Filtering & Instant Search**: Search components by part number, value (e.g. 10k), package, category, or drawer ID.
- **Interactive Drawer Inspector**: Visual drawer-level auditing to inspect components inside any warehouse drawer.
- **Bulk Stock Adjustments**: Multi-drawer stock increment and decrement modal with live balance validation.
- **HMAC-SHA256 Signed Backups**: Digitally-signed backup and restore mechanism protecting data integrity.
- **Excel & CSV Export**: Export inventory with formatting, custom headers, and UTF-8-BOM support.
- **Modular PyTest Suite**: Comprehensive automated test coverage (45 test cases).

## 🚀 Quick Start

### Installation
```bash
pip install -r requirements.txt
```

### Launch Application
```bash
python main.py
```

### Run Tests
```bash
pytest
```
